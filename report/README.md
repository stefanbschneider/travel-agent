# Technical report

**[`fabiundstefan.pdf`](fabiundstefan.pdf)** — *Agentic Travel Planning: Where AI Helped, and Where
It Did Not* (Stefan Schneider, Fabian Missbrenner). The 4-page Phase 2 report for the [Travel
Planning Challenge at IJCAI 2026](https://chinatravel-competition.github.io/IJCAI2026/), in the
official IJCAI template.

It covers:

- the system: parsing into branch-local constraints, the deterministic grounded solver, repair and
  densification, and the acceptance gate;
- the evidence: official leaderboard readings and the paired local measurements behind the submitted
  `v2`, including a negative result for LLM-based parsing and repair;
- the process: using the competition as a low-risk experiment in near-continuous, multi-agent AI
  development, and its limits.

The report was written before the held-out test set was published. For why the held-out score
lagged the local measurements, see the
[postmortem (R38)](../docs/tpc_phase2_eval.md#r38--held-out-postmortem-why-the-improvements-did-not-transfer-closed-2026-09-29-retrospective-only).

## Build

```bash
cd report && make          # pdflatex -> bibtex -> pdflatex x2 -> fabiundstefan.pdf
make clean                 # remove aux/log/bbl/blg/out, keep the PDF
```

On macOS with MacTeX, prefix `PATH="/Library/TeX/texbin:$PATH"`. On Debian/Ubuntu:

```bash
apt-get install -y --no-install-recommends \
  texlive-latex-base texlive-latex-recommended texlive-fonts-recommended
```

`make` warns above 4 pages. The figures are committed as PDFs, so the report builds without Python;
regenerate them only when a number changes:

```bash
.venv/bin/python scripts/report_figures.py            # writes report/figures/*.pdf
.venv/bin/python scripts/report_figures.py --check    # verify every cited artifact, plot nothing
```

Every number in the `.tex` has a comment naming its source, tagged `ROW` (whole-set run under
[`../results/phase2_baselines/`](../results/phase2_baselines/)), `SCREEN` (paired A/B at reduced
scale) or `PORTAL` (the organizers' returned score). Keep that convention when editing.
