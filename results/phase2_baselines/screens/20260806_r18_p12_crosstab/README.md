## What it computes

- **official** = pass iff a query's uid is in `schema_pass_id ∩ commonsense_pass_id ∩ logi_pass_id`,
  replicating `eval_tpc.py`'s own `all_pass_id` computation exactly (oracle-fed, local-only — this
  split carries released oracle fields; see [CLAUDE.md](../../../../CLAUDE.md#non-negotiable-invariants)
  on why that is only ever an evaluation-side computation, never fed to the agent).
- **parsed** = pass iff the run's own per-query `telemetry.json.self_score` reports `schema_ok`,
  `commonsense_ok` and `logical_ok` all `true` — the exact live output of
  `chinatravel.agent.phase2.selfscore.score_plan`'s `PlanScore.constraints_ok`, taken from what the
  scheduler actually computed against the variants it searched, not recomputed independently (which
  would risk deriving a different parse than what was actually solved against).

The script cross-checks itself against the row: `official_pass_rate` must equal the row's
`official_scores.FPR`, and `parsed_pass_rate * n` must equal the row's `constraints_ok`. Both matched
exactly for this run (`90.666...%` = `136/150`; `125/150`).
